# Erasmus · Star Voyage

Videojoc en valencià, castellà i anglès inspirat en el projecte Erasmus+ de l’IES Gregori Maians d’Oliva.

La ruta té nou etapes: Oliva → Estocolm → França → Opwijk → Zlín → Lyon → Oslo → Landau → Chórzow. Landau correspon a una mobilitat de grup a Alemanya.

## Jugar
Obre `index.html` al navegador. Fletxes per canviar de carril, espai per saltar i P per pausar. Inclou controls tàctils.

## GitHub Pages
A Settings → Pages selecciona Deploy from a branch, la branca main i la carpeta / (root).

No necessita dependències ni compilació. El rècord es desa al navegador.
